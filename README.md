# Home Assistant Config (Public)

Este repositório contém uma versão curada e pública de partes da minha configuração do Home Assistant, compartilhada para fins de referência e ajuda com a comunidade.

Arquivos com lógica de rotina pessoal (automações, horários, presença) foram propositalmente excluídos ou generalizados por questões de privacidade e segurança.

O repositório completo é mantido de forma privada.
